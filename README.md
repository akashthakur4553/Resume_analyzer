# 📄 Resume Analyzer
Resume Analyzer is a web-based application designed to assist recruiters and job seekers by evaluating resumes against specific job descriptions. Leveraging Natural Language Processing (NLP) techniques, the tool extracts and analyzes key information from resumes to determine their relevance to desired job roles.

🚀 Features
📑 Resume Parsing: Extracts essential details such as skills, experience, and education from uploaded resumes.

🧠 NLP-Based Analysis: Utilizes NLP to assess the alignment between resume content and job requirements.

📊 Matching Score: Provides a compatibility score indicating how well a resume matches a given job description.

🖥️ User-Friendly Interface: Built with Flask, HTML, and CSS to ensure a seamless user experience.

🛠️ Tech Stack
Backend: Python, Flask

Frontend: HTML, CSS

Libraries: spaCy, NLTK, PDFMiner

📌 Use Cases
Recruiters: Quickly screen and shortlist candidates based on resume relevance.

Job Seekers: Evaluate and enhance resumes to better fit targeted job descriptions.
